# C6 — 面板前端 SPA

父任务：`08-02-firecrawl-key-proxy`。API 契约见父任务 `design.md` §7 与 C5。

## Goal

用 Vue 3 写一个三页面的管理面板：总览、上游 Key 管理、API Key 管理。构建产物输出到 `internal/webui/dist`，由 Go 通过 `go:embed` 嵌入，运行时仍是单进程。

## Requirements

### R6.1 工程

- Vue 3 + Vite + TypeScript + Tailwind CSS，源码在 `web/`。
- `vite.config.ts` 的 `build.outDir` 指向 `../internal/webui/dist`，`emptyOutDir: true`。**这是 `go:embed` 能工作的前提**——embed 指令只能引用本包目录树内的文件。
- 开发时通过 Vite 的 `server.proxy` 把 `/api` 转发到本地运行的 Go 服务，避免开发期跨域。
- `internal/webui/dist` 不入版本库（`.gitignore`），但需保证 `go build` 前已构建——C7 的 Dockerfile 负责这个顺序。

### R6.2 登录

- 启动时调用 `GET /api/admin/session`，未登录则显示登录页。
- 登录页只有一个密码输入框与提交按钮。错误时显示提示，不区分「密码错」与其他失败原因。
- 任意 API 返回 401 时自动跳回登录页。

### R6.3 总览页

- 额度池进度条：`credits_remaining_sum / credits_total_sum`。
- 各上游 Key 的状态卡片：名称、脱敏 Key、状态徽标（`可用` 绿 / `冷却` 黄 / `额度耗尽` 灰 / `已失效` 红 / `已禁用` 灰）、剩余额度、冷却中的显示倒计时。
- 按固定间隔（默认 5 秒）自动刷新，页面上显示「N 秒前更新」。页面不可见时（`document.hidden`）暂停轮询。

### R6.4 上游 Key 管理页

- 表格：备注名、脱敏 Key、状态、冷却剩余、剩余额度、累计调用数、最后错误、操作。
- 新增：粘贴 Key + 填备注 → 提交。
- 行操作：启用/禁用切换、重置状态（仅在 `exhausted`/`invalid` 时可用）、刷新额度、删除（需二次确认）。
- 删除确认对话框需说明「该 Key 的进行中任务将无法再查询」。

### R6.5 API Key 管理页

- 表格：名称、前缀、调用数、最后使用时间、创建时间、状态、操作。
- 创建：填名称 → 提交 → **弹窗展示一次完整明文并提供复制按钮**，弹窗中明确提示「关闭后无法再次查看」。
- 吊销需二次确认。已吊销的行置灰并标注。

### R6.6 通用

- 支持暗色主题，跟随系统偏好，并可手动切换、持久化到 `localStorage`。
- 所有写操作结果以 Toast 反馈（成功/失败）。
- 表单提交期间禁用按钮，避免重复提交。
- 界面文案全部为简体中文。

## Acceptance Criteria

- [ ] `cd web && npm ci && npm run build` 成功，产物出现在 `internal/webui/dist`，含 `index.html` 与 `assets/`。
- [ ] 构建后 `go build ./...` 通过，`go:embed` 未报「no matching files」。
- [ ] 运行二进制后访问根路径，未登录时展示登录页；密码正确后进入总览。
- [ ] 刷新浏览器后仍处于登录态（cookie 生效）；点登出后回到登录页。
- [ ] 直接访问 `/keys` 不出现 404，SPA 路由正常（依赖 C5 的兜底）。
- [ ] **AC8 前端侧**：在上游 Key 页新增一个 Key，列表立即出现该条目，无需刷新页面或重启服务。
- [ ] **AC9 前端侧**：创建 API Key 后弹窗展示完整明文与复制按钮；关闭弹窗后列表中只显示前缀，无任何途径再看到明文。
- [ ] 冷却中的 Key 在总览页显示倒计时，倒计时归零后的下一次轮询状态变为「可用」。
- [ ] 切换到暗色主题后刷新页面，主题保持不变。
- [ ] 后端返回 401 时自动跳转登录页，不出现空白页或控制台报错。
- [ ] 页面切到后台标签页时停止轮询（可在 Network 面板观察到请求停止）。
- [ ] `npm run build` 无 TypeScript 类型错误。

## Out of Scope

- 用量图表、请求日志检索、告警配置。父任务已明确排除。
- 多语言、无障碍专项优化、移动端适配（桌面浏览器可用即可）。
- 前端单元测试框架。本任务的验收以手工核对与构建通过为准；核心逻辑在后端且已有测试覆盖。

## Notes

API 类型定义（`web/src/api/types.ts`）应与 C5 的响应结构一一对应，手工维护即可，不引入代码生成。若发现后端少返回了某个字段，回到 C5 补充，不要在前端做推导或拼接——那会让契约变成隐性的。
